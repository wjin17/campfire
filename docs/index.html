Campfire

Vocal effects and synced lyrics for whatever you're playing

Download for Windows Download for Mac (Apple Silicon)
Install on Windows
  1. Unzip the downloaded Campfire-windows.zip.
  2. Open the extracted folder and run Campfire.exe.
Install on Mac (Apple Silicon only)
  1. Unzip the downloaded Campfire-mac-arm64.zip.
  2. The build isn't notarized, so macOS will quarantine and refuse to open it. Clear the quarantine flag and ad-hoc sign it from Terminal: 
xattr -cr Campfire.app
codesign --force --deep -s - Campfire.app
  1. Then open Campfire.app as usual.

Updates are silent. Campfire checks GitHub Releases in the background and pulls down new versions automatically — you never have to reinstall.

For accurate song detection in a browser, install the Campfire browser extension (load-unpacked instructions in its README).
